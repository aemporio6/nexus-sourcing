# v3 module contract (read with SPEC.md). All modules are plain scripts concatenated into one `<script>`; everything is global.

## Files & who writes them
- `core.js` (done) — state `S`, data `D`, helpers. READ IT: every function you need is there (dates, `L()`, `items()`, `fmt`, `poState`, `stockOf`, `reorderInfo`, `relatedDocs`, `attention`, `calEvents`, `searchAll`, `searchText`, `resolveRef`, `go`, `openDoc`, `F(page)`/`setF`/`clearF`, `writeDoc/updateDoc/trashDoc/restoreDoc/setupPatch`, `beginBatch/endBatch`, `can`, `toast`).
- `forms.js` + `forms2.js` (done) — `openForm(key, ctx)`, `formShell(key)`, `fields(key)`, `inputFor`, `selectHtml`, `optsHtml`, `listOpts`, `SAVE[key]()`, `rowChanged`, `addRow`, `rmRow`, `inlineAdd/inlineCommit`, `applyDraft`, `uploadFile`.
- `views.js` — `render()` and every page `vXxx(viewEl)`; helpers `crumb`, `sel`, `filterBar`, `savedViewsBar`, `listFooter`, `datePresetMatch`, `sortRows`.
- `drawers.js` — `renderDrawer()` and `openXxx` renderers (they RETURN html for the drawer body/footer; `S.drawer={col,id}` is already set by `openDoc`).
- `setup.js` — `vSetup` tabs, `vImport` + import engine, exports (xlsx), PDFs (jsPDF), `exportView`.
- `events.js` — all DOM event handlers + boot.

## Render contract
`render()` (views.js):
1. `nav()` draws `#rail` (desktop) and `#tabbar` (phone: Home, Purchases, Shipments, Stock, More) with `aria-current="page"` on the active one and action badges (`S.badges` computed from `attention()`: counts by col).
2. Draws `#view` for `S.view.k` via map `{home:vHome, purchases:vPurchases, shipments:vShipments, payments:vPayments, stock:vStock, products:vProducts, parties:vParties, calendar:vCalendar, tools:vTools, refs:vRefs, reports:vReports, import:vImport, attention:vAttention, log:vLog, trash:vTrash, setup:vSetup, more:vMore, doc:vHome}`.
3. Then `#layer`.innerHTML = `S.drawer?.form ? formShell(S.drawer.form) : S.drawer ? renderDrawer() : ""`. Keep drawer scrollTop: before replacing, read `$(".drawer .db")?.scrollTop` and restore after.
4. Skip steps 1–2 when `S.holdRender` is true or `document.activeElement` is inside `#setupbody`, `.drawer`, or `#view [data-tool]`.
5. Enable/disable `#backb` (`S.hi>0`), `#fwdb` (`S.hi<S.hist.length-1`), `#undob` (`S.undo.length`), `#redob` (`S.redo.length`); bell dot when `attention().some(a=>a.sev>=2)`.
6. Lists: wrap rows in `<div id="listbody">`; `renderList()` re-renders only `#listbody` + `#listcount` when called from search/filter input.

## List pages (purchases, shipments, payments, stock, products, parties)
- Filters live in `F(page)` (per page). Filter controls: `<select data-f="key">` / `<input data-f="key">` / `<button class="chipb" data-f-toggle="key" aria-pressed>`; `sel(page,key,label,opts)` helper builds a select with "label: all" first; options = Setup list ∪ distinct values in data (append unmapped values with "(unmapped)").
- Date presets key `date` with values: `today,7d,30d,90d,month,lastm,quarter,year,custom` and custom inputs `data-f="from"`, `data-f="to"`. Implement `inDate(iso,f)` once in views.js with `today()/addDays`. Year ▼ (`year`) is disabled when `date` is set.
- Amount range: `data-f="min"`, `data-f="max"` (GBP). Tags: `data-f="tag"`. Search box per list: `<input data-f="q">` uses `score(searchText(col,x), q)`.
- Sort: `<select data-f="sort">` options per page (e.g. `date_desc, date_asc, amount_desc, amount_asc, owing_desc, eta_asc, name_asc, days_asc`). Desktop header row `.lhead` with `data-sort="key"` buttons.
- Saved views: `savedViewsBar(page)` reads `D.views.filter(v=>v.page===page)`; buttons `data-sv="id"`; save = `data-act="saveview"` with inline `<input id="svname">`; `data-act="delview" data-id`; `data-act="renview" data-id`. Highlight when `normF(v.f)===normF(F(page))` where `normF` drops empty keys and sorts keys.
- Count: `<span id="listcount">N of M</span>`; `S.limit[page]` (default 60) + `data-act="more"` and `data-act="all"`.
- Bulk: a checkbox per row `<input class="ck" type="checkbox" data-sel="id">`; `S.sel[page]` holds ids; when any selected show `.bulk` bar with `data-act="bulk" data-op="archive|close|arrived|tag|export|trash"`.
- Row: `<div class="row" role="button" tabindex="0" data-open="col" data-id="…">` (not `<button>`), children `.ck .ref .d .amt .stc`; original-currency amount is primary (`.amt b`), £ secondary. Export this view: `data-act="exportview"`.
- Clear filters: `data-act="clearf"`.

## Drawers (drawers.js)
`renderDrawer()` picks by `S.drawer.col`: `openPO, openShip, openPay, openInsp, openReceipt, openMove, openCredit, openProduct, openParty, openImport`. Each returns `{title, status:{text,cls}, body, footer}` and `renderDrawer` wraps: `<div class="scrim" data-act="close"></div><div class="drawer" role="dialog" aria-modal="true" aria-labelledby="dtitle"><div class="dh"><h2 id="dtitle">…</h2><span class="pill …">status</span><button class="x" data-act="close" aria-label="Close">×</button></div><div class="db">body</div><div class="df">footer</div></div>`. If the doc is not found → body "not found". Footer: ≤3 primary buttons + `<div class="morem"><button class="btn" data-act="moremenu">More ▾</button><div class="menu" id="moremenu" hidden>…</div></div>` for the rest.
Common blocks (helpers in drawers.js): `refBox(text)` (ref text + `data-act="copytext" data-text`), `relatedBlock(col,id)` (`relatedDocs` → `.related` buttons `data-open data-id` with `<small>why</small>`), `docsBlock(col,x)` (every non-archived `docType` item whose `for` includes col: ✓/○, link input `data-act="doclink" data-col data-id data-doc` + Enter, file input `data-act="docfile" …`, open link), `tagsBlock(x)` (`.tagc`), `stepper(listKey,currentId)` (uses items with step≥0; `.st.d` done, `.st.c` current, text in `<span>`), `kv(pairs)`, `notesBlock`, `linksBlock(x.links)`, `auditLine(x)` (created/updated by/at).
Actions (data-act) used in drawers — events.js implements exactly these: `edit` (data-col data-id → openForm with `{edit}`), `copy` (purchase), `trash` (data-col data-id), `restore`, `setstatus` (data-col data-id data-status), `pay` (data-po [data-ms] | data-sh | data-ref data-party), `ship` (data-po), `receive` (data-sh | data-po), `inspect` (data-po), `reinspect` (data-id), `credit` (data-po | data-rc), `reorder` (data-sku), `move` (data-sku [data-loc] [data-type]), `approve` (data-id), `markpaid` (data-id), `unlock`, `lock`, `cancelpay` (data-id), `refund` (data-id), `pdf` (data-col data-id), `fwdpdf` (data-id), `statement` (data-party), `archiveparty` (data-id), `mapsku` (change event on `<select data-act="mapsku" data-po data-i>`), `linkorders` (data-sh → openForm shipment edit), `mergeproduct` (data-sku: shows inline select `data-act="mergeinto"`), `copytext` (data-text), `doclink`, `docfile`, `open` via `data-open`.

## Setup (setup.js)
Tabs via `<button data-setup="tab" aria-pressed>`: companies, banks (incl. people), emails, locations, lists, numbering (numbering + refType groups + refPatterns + counters), forms, rates (rates history + fees + defaults + vatHistory), users, aliases, backup, legacy (map legacy values).
Every editable control: `<input data-sp="path.in.setup" …>` / `<select data-sp>` / checkbox `data-sp` — events.js on `change` calls `setupPatch(path, value, label)` (number inputs → number, checkbox → boolean). Duplicate check on rename: events.js checks sibling labels/names for `lists.*.items.*.label`, `companies.*.name`, `banks.*.name`, `emails.*.address`, `locations.*.name`, `people.*.name` and refuses with a toast.
Add buttons: `data-sadd="companies|banks|people|emails|locations|listitem|listsub|newlist|user|alias|rate|vat|field|tag|company"` with `data-list`, `data-parent`, `data-form` as needed; events.js `setupAdd(what, t.dataset)` pushes a sensible blank item with unique id and refreshes. Archive toggle `data-sarch="path"`; reorder `data-smove="path" data-dir="-1|1"`; default toggle `data-sdef="path"`.
Lists tab: list chips `data-listkey`; coded lists show their `fields` as extra inputs per item; `days/basis/divisor` etc. are just `fields`. Items show their id (small) and the sub-item parent select.
Forms tab: form chips `data-formkey`; per field: label input `data-sp="forms.<form>.over.<k>.l"`, hidden checkbox `…over.<k>.hidden`, required `…over.<k>.req`, order number `…over.<k>.order`, default `…over.<k>.default`, hint. Custom fields: `data-sadd="field" data-form` → new row where user sets key, label, type (select: text,num,int,date,bool,textarea,link,list,opts), list (select of list keys when type=list), opts (comma text).
Legacy tab: scan `D.purchases/payments/shipments/parties` for `legacy{}` values; per distinct (field,value) show a select of valid targets (company/bank/list items/locations) and `data-act="maplegacy" data-col data-field data-value` → events.js updates all matching docs (batch) and clears `legacy[field]`.
Backup tab: `data-act="exportsetup"` (download JSON via `downloads` capability or Blob link), `data-act="importsetup"` (file input), note about nightly Drive backup in the real build.
Import page (`vImport`): kind ▼ (importKind), file input `#imp_file`, date format ▼, channel→location table (marketplace.loc), mapping preview with `data-impmap`, SKU alias row `data-impalias`, aggregated preview, `data-act="runimport"`; engine `handleImport(file)`, `autoMap`, `runImport()` creates `IMP-` doc + moves (sales → `sold` moves from marketplace loc; negative → `return`; count → count diffs) in one batch; `data-act="undoimport" data-id` trashes all docs listed in the import. Store `S.imp` and re-render preview from it in `vImport`.
Exports: `exportXlsx(scope)` scope `all|accountant|view` (view uses current filtered rows from `S.lastRows`), strips `bank`/`beneficiary`/`email` unless `can("bank")`. PDFs: `pdfDoc(col,id)` (PO/payment/receipt), `forwarderPdf(shNo)` (packing list with company VAT/EORI from `company(po.account)`), `statementPdf(partyCode)`.
